The gap

Most workout apps ask too much from someone under a bar.

RepFast is not a social feed, coaching platform, ad surface, or cloud dashboard. It is a lean gym-floor tool for the moment when the lifter has shaky hands, poor signal, and a rest clock already running.

Too many screens

Menus, workout builders, feeds, and prompts get between the user and the only thing they need to capture: weight and reps.

Signal-dependent

A gym basement should never break the log. V1 stores workouts locally and avoids mandatory cloud sync.

Spreadsheet thinking

Raw history is useful later. During a session, the app should answer one question fast: did this beat last time?

Product idea

The 10-second log loop.

Open, lift, log, compare. RepFast remembers the last values, keeps controls oversized, starts rest automatically, and translates the session into a plain-English performance card.

1

Open to active lift

No home feed. No signup wall. The next planned exercise is already on screen.

2

Confirm defaults

Weight and reps prefill from the previous time. Most sets need one tap.

3

Start rest timer

Logging a set immediately starts the rest clock and keeps the next action visible.

4

Compare instantly

The payoff is not a chart hunt. It is a simple “today vs last time” answer.

Real gym moment

Roadmap

MVP first. Power later.

01 Offline MVP

Local workout history, exercise list, previous-set defaults, log button, auto-rest timer, and today-vs-last-time card.

02 Optional sync

Cloud backup becomes opt-in after the core loop is trusted. The gym-floor experience remains offline-capable.

03 Lift utilities

Plate calculator, optional RPE, and simple progression prompts that do not clutter the logging screen.

04 Wearable and voice logging

Later input modes for chalky hands and phone-free sets, only after the manual loop is fast enough to beat paper.
